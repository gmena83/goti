## Writing the prompts and seeing the results

I simply wrote the prompt. It included the game I wanted to build, along with a description of what the overall design and feel of the game should be. So here it goes, **Build a minimal browser-based game where transparent, pastel-colored bubbles float up the screen at random intervals and positions. When I click on a bubble, it disappears with a satisfying “pop” sound and a small animation. Make sure the background is soft and calming, and the game keeps going infinitely — no score, no stress, just bubbles and pops. Bonus if you add some subtle ambient music.**
