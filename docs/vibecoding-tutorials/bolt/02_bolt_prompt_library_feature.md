## Overview

Bolt's new Prompt Library feature is designed to accelerate the "vibe coding" process by making prompt engineering faster and more efficient. This feature eliminates the need to retype the same prompts repeatedly and provides access to expert-level prompts for common development tasks.

## Key Features

### Custom Prompt Management
The Prompt Library allows users to:
- **Create** custom prompts tailored to their specific needs
- **Save** frequently used prompts for quick access
- **Favorite** important prompts for even faster retrieval
- **Organize** prompts for easy reuse across projects

### Pre-loaded Expert Prompts
The library comes pre-loaded with a wide range of expert-level prompts organized into categories:
- **Accessibility** - Implementing accessible features and compliance
- **Performance** - Optimizing page load speed and application performance
- **SEO** - Search engine optimization improvements
- **Usability** - Enhancing user experience and interface design

### One-Click Complex Tasks
With a single click, users can execute complex development tasks such as:
- Implementing a fully accessible dark mode
- Improving page load speed
- Optimizing the entire navigation structure
- Adding comprehensive accessibility features

## How to Use the Prompt Library

### Accessing the Library
There are two ways to access the Prompt Library:
1. **Click the library icon** in the Bolt interface
2. **Use the `/` (slash) command** for quick access

### Quick Access to Favorites
The slash command (`/`) also surfaces favorited prompts for even faster access, allowing developers to execute their most-used prompts with minimal effort.
