## Video Description

Tired of retyping the same prompts over and over? This video demonstrates the brand new "Prompt Library" feature in Bolt. The feature allows users to save and reuse their favorite prompts, as well as access a pre-set library of commands to perform tasks like implementing dark mode, improving accessibility, optimizing SEO, and more. The video walks through creating a custom prompt, favoriting it, and then using pre-set library prompts to iterate on a sample AI-generated application.

## Key Concepts and Features

The video introduces the **Prompt Library** feature in **Bolt.new**, which aims to 10x "vibe-coding" speed by:

1.  **Storing Custom Prompts:** Users can create, categorize (e.g., "performance"), and save their own frequently used prompts.
2.  **Favoriting Prompts:** Easy access to the most-used prompts via a "favorite" section.
3.  **Pre-set Library:** A built-in menu of existing prompts for common development tasks:
    *   Implement dark mode
    *   Improve accessibility
    *   Optimize SEO
    *   Improve overall usability
    *   Add error handling
    *   Create a web app manifest generator
4.  **Easy Access:** The library is accessible via a dedicated icon or by simply typing `/` in the command box.

## Transcript Highlights and Examples

### Creating a Custom Prompt

The speaker demonstrates creating a custom prompt under the **Performance** category:

> **Category:** Performance
> **Name:** Improve speed load page
> **Prompt:** Look at all the components behind the scenes in the back end and try to find ways to speed up the view and speed up the overall load time.

### Example 1: Implementing Dark Mode

The speaker generates a sample fitness coach app and then uses a pre-set prompt to implement dark mode.

**Prompt Used:**
\`\`\`
Generate code for implementing a fully accessible dark mode toggle on my website. Include CSS variables for theming, proper color contrast in both modes, persistent user preference storage, and respect for prefers-color-scheme media query. Ensure smooth transitions between themes.
\`\`\`

**Result:** A beautiful dark mode design is implemented with a single-shot prompt.

### Example 2: Optimizing Navigation

The speaker then uses another pre-set prompt to improve the app's navigation.

**Prompt Used:**
\`\`\`
Evaluate my website's navigation structure and generate recommendations for improvement based on UX best practices. Consider information architecture, menu depth, naming conventions, and mobile usability. Provide code for implementing a more intuitive navigation system.
\`\`\`

**Result:** The navigation structure is changed to a clean, organized, and collapsible sidebar.
