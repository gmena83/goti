### n8n@1.122.0
- **Instance-level MCP connections (beta)**: Connect AI agents to n8n workflows
- **New nodes**: Enhanced AI and automation capabilities
- **Bug fixes**: Improved stability and performance

### n8n@1.121.0
- **Project-level variables**: Better environment management
- **Improvements to Environments**: Enhanced deployment workflows
- **Custom date ranges for Insights**: Better analytics

### n8n@1.120.0
- **AI Workflow Builder**: Now available to Enterprise Cloud users
- **Enhanced debugging**: Better error tracking and logging

### n8n@1.119.0
- **Guardrails Node**: Add safety checks to AI workflows
- **Performance improvements**: Faster workflow execution

### n8n@1.118.0
- **Data migration tool**: Easier migration between instances
- **Source Control HTTPS support**: Better Git integration
