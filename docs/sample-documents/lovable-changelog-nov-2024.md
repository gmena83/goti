# Lovable Changelog - November 2024

## Major Updates

### Lovable 2.0 Launch
A significant overhaul introduced real-time collaboration through a new multiplayer mode, allowing teams to work together in a unified workspace. This update also included a rebranded user interface, simplified pricing structures, and a Security Scan feature to detect vulnerabilities in published applications connected to Supabase.

### Lovable AI
Users can now develop AI-native applications by simply providing prompts, with Lovable managing the necessary API access for providers like Google Gemini. This functionality supports the creation of specialized conversational AI assistants, image generators, and coaching applications. Pricing for Lovable AI is based on usage.

### Model Context Protocol (MCP) Integrations
This powerful addition allows Lovable AI agents to directly connect with external tools such as Notion, Miro, Jira, Confluence, and n8n. These integrations enable the AI to access and process data, incorporating PRDs, tickets, and wireframes directly into development workflows, and supporting integration with over 400 applications.

### Versioning 2.0
The platform now offers enhanced change tracking with an improved history view, akin to Google Docs, along with bookmarking capabilities and simplified restoration of previous versions.

## User Experience Improvements

### Visual Edits & Design View
A new Design view offers a dedicated panel for design tools, including updates to Visual Edits, Themes, and AI-powered image generation. Users can directly modify text, adjust styling elements like margins and colors, and select multiple elements for simultaneous editing.

### Integrated Domain Management
Users can now purchase custom domains directly from their project settings via a partnership with IONOS and easily remove existing custom domains.

### Optimized Project Loading
Large projects now load faster due to an optimized loading mechanism that only loads additional content as the user scrolls.

## Developer Features

### Dev Mode
Paid users can now activate Dev Mode to directly edit project code within Lovable, with changes seamlessly saved to GitHub.

### Streamlined Setup Flows
The onboarding process for GitHub and Supabase integrations has been revamped to reduce complexity.
